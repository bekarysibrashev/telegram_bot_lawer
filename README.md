## 🚀 Пошаговая установка (для новичков)

### Шаг 1 - Установите Python

1. Откройте сайт: https://www.python.org/downloads/
2. Нажмите **"Download Python 3.11"** (или новее)
3. Установите. **ВАЖНО:** при установке поставьте галочку **"Add Python to PATH"**
4. Проверьте установку - откройте терминал и напишите:
   ```
   python --version
   ```
   Должно показать: `Python 3.11.x`

### Шаг 2 - Скачайте проект

Если у вас есть Git:
```bash
git clone https://github.com/bekarysibrashev/telegram_bot_lawer.git
cd legal_bot
```

Или просто скачайте файлы и положите в папку `legal_bot`.

### Шаг 3 - Установите зависимости

Откройте терминал в папке проекта и выполните:
```bash
pip install -r requirements.txt
```

### Шаг 4- Получите Telegram Bot Token

1. Откройте Telegram, найдите бота **@BotFather**
2. Напишите `/newbot`
3. Введите **имя бота**, например: `Qazaq Legal AI`
4. Введите **username** (уникальный), например: `qazaq_legal_bot`
5. BotFather выдаст токен вида: `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
6. Скопируйте его — это ваш `TELEGRAM_BOT_TOKEN`

### Шаг 5 — Подключите бесплатный AI

#### Groq API (проще, рекомендуется)

1. Зайдите на https://console.groq.com
2. Нажмите **"Sign Up"** → зарегистрируйтесь (бесплатно)
3. Перейдите в раздел **API Keys**
4. Нажмите **"Create API Key"**
5. Скопируйте ключ - это ваш `GROQ_API_KEY`

Лимиты бесплатного Groq:
- ~14,400 запросов/день
- Модель LLaMA 3 (8B)
- Без кредитной карты


### Шаг 6 — Настройте конфигурацию

1. Скопируйте файл примера:
   - Windows: `copy .env.example .env`
   - Mac/Linux: `cp .env.example .env`

2. Откройте файл `.env` в блокноте и заполните:
   ```
   TELEGRAM_BOT_TOKEN=7123456789:AAHxxx...ваш_токен
   
   # Если используете Groq:
   AI_PROVIDER=groq
   GROQ_API_KEY=gsk_xxx...ваш_ключ
   GROQ_MODEL=llama3-8b-8192
   
   ```

### Шаг 7 - Запустите бота

```bash
python bot.py
```

Если всё правильно, увидите:
```
INFO - 🚀 Qazaq Legal AI Bot запущен...
```

Теперь найдите вашего бота в Telegram и напишите `/start`!

## 💬 Примеры диалогов

### Пример 1: Невыплата зарплаты

**👤 Пользователь:**
> Работодатель не платит зарплату уже 3 месяца. Говорит "денег нет". Я работаю официально по трудовому договору. Что делать?

**🤖 Бот:**

📌 **Краткий анализ**
Задержка заработной платы является нарушением Трудового кодекса РК. Работодатель обязан выплачивать зарплату не реже одного раза в месяц. 3 месяца задержки — серьёзное нарушение, у вас есть реальные правовые инструменты.

⚖️ **Применимые нормы**
• Трудовой кодекс РК, ст. 113 — сроки выплаты заработной платы
• Трудовой кодекс РК, ст. 131 — право работника на приостановление работы при задержке
• КоАП РК, ст. 87 — административная ответственность работодателя
• Уголовный кодекс РК, ст. 148 — при задержке свыше 2 месяцев

🔧 **Рекомендуемые действия**
1. Напишите работодателю **официальную претензию** (письменно, с подписью и датой)
2. Обратитесь в **Государственную инспекцию труда** (ГИТ) — онлайн через e-gov.kz
3. Подайте жалобу в **прокуратуру** по месту нахождения организации
4. Параллельно подайте иск в **суд** о взыскании зарплаты + компенсации
5. Соберите доказательства: трудовой договор, расчётные листки, переписку

📊 **Оценка ситуации**
🟢 **Высокая вероятность успеха** — при наличии официального трудового договора суды РК в подавляющем большинстве случаев встают на сторону работника в вопросе невыплаты зарплаты.

⚠️ *Это информация носит ознакомительный характер и не является официальной юридической консультацией.*

### Пример 2: Залив квартиры соседом

**👤 Пользователь:**
> Сосед сверху затопил мою квартиру. Ущерб — повреждён потолок и мебель. Как получить компенсацию?

**🤖 Бот:**

📌 **Краткий анализ**
Это классический случай причинения имущественного вреда по Гражданскому кодексу РК. Ваше право на возмещение ущерба защищено законом. Ключевой момент — правильно зафиксировать ущерб.

⚖️ **Применимые нормы**
• ГК РК, ст. 917 — общие основания ответственности за причинение вреда
• ГК РК, ст. 934 — причинение вреда имуществу
• Закон РК "О жилищных отношениях" — ответственность за содержание жилья

🔧 **Рекомендуемые действия**
1. **Сразу** вызовите аварийную службу КСК/УК — зафиксируйте причину залива официально
2. Составьте **акт о заливе** с подписью соседа и представителя КСК
3. Сделайте **подробные фото и видео** ущерба
4. Закажите **независимую оценку ущерба** (оценочные компании)
5. Направьте соседу **письменную претензию** с требованием возместить ущерб
6. При отказе — подайте иск в **суд** (при ущербе до 300 МРП — в районный суд)

📊 **Оценка ситуации**
🟢 **Высокая вероятность успеха** — при наличии акта о заливе и независимой оценки ущерба судебная практика по таким делам в РК устойчива в пользу пострадавшей стороны.

⚠️ *Это информация носит ознакомительный характер и не является официальной юридической консультацией.*

### Пример 3: Открытие ИП

**👤 Пользователь:**
> Хочу открыть маленький магазин одежды. Как оформить ИП в Казахстане и сколько налогов платить?

**🤖 Бот:**

📌 **Краткий анализ**
Регистрация ИП в Казахстане сейчас максимально упрощена — можно сделать онлайн за 1 день без визита в госорганы. Для небольшого магазина подойдёт специальный налоговый режим.

⚖️ **Применимые нормы**
• Налоговый кодекс РК — специальные налоговые режимы для МСБ
• Закон РК "О государственной регистрации юридических лиц и учётной регистрации филиалов"
• Предпринимательский кодекс РК — права и обязанности ИП

🔧 **Рекомендуемые действия**
1. Зарегистрируйте ИП на **egov.kz** (раздел "Бизнес" → "Регистрация ИП") — бесплатно, онлайн
2. Выберите налоговый режим:
   - **Упрощённая декларация** (форма 910) — 3% от дохода, раз в полгода
   - Порог дохода: до ~24 000 МРП в год
3. Зарегистрируйтесь плательщиком **ОПВ и ОСМС** через Кабинет налогоплательщика
4. Откройте расчётный счёт в любом банке РК
5. Рассмотрите подключение **онлайн-кассы** (обязательно для розничной торговли)

📊 **Оценка ситуации**
🟢 **Регистрация:** простая процедура без сложностей
🟡 **Налогообложение:** рекомендую уточнить актуальные ставки МРП на текущий год у налогового консультанта

⚠️ *Это информация носит ознакомительный характер и не является официальной юридической консультацией.*

## ❓ Частые вопросы

**Q: Бот работает на казахском языке?**
A: Да! Напишите вопрос на казахском — получите ответ на казахском.

**Q: Данные сохраняются?**
A: В MVP-версии история хранится только в памяти (до перезапуска бота). Для продакшена можно добавить Redis или PostgreSQL.

**Q: Можно развернуть на сервере?**
A: Да. Подойдёт любой VPS от ~$3/мес (например, TimeWeb, Reg.ru, DigitalOcean). Или бесплатно на Railway.app / Render.com.
